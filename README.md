# Lalit Choudhary — Senior WordPress Developer Portfolio

Static personal portfolio for **Lalit Choudhary**, a Senior WordPress Developer based in Nashik. It presents 4.5+ years of WordPress-focused work: custom themes and plugins, ACF / Gutenberg, WooCommerce, REST APIs, and headless WordPress — plus the original twelve live projects.

**Live site:** [https://lalit-choudhary-wp.github.io/wordpress-portfolio/](https://lalit-choudhary-wp.github.io/wordpress-portfolio/)

## Stack

- Semantic HTML
- Dark cinematic CSS (custom properties, grid, marquee, grain, scroll-reveal)
- Vanilla JavaScript (IntersectionObserver, sticky nav, optional cursor follower, reduced-motion support)
- GitHub Pages (no build step)

## Run locally

Serve the repo root so asset paths resolve the same way they do on GitHub Pages:

```bash
python3 -m http.server 8080
```

Then open [http://localhost:8080](http://localhost:8080).

You can also open `index.html` directly in a browser.
